1. તમારી Google Sheet ખોલો → Extensions → Apps Script → કોડ પેસ્ટ કરો (ચેટમાં નીચે આપેલો છે).
2. Deploy → New deployment → Web app કરો, Access: Anyone રાખો.
3. જે લિંક (URL) મળે એ નીચે પેસ્ટ કરો, અને તમારો ઈમેલ પણ નાખો — જેથી નવી એન્ટ્રી આવે ત્યારે તમને મેઇલ મળે.
